# ERP-Marketplace
### ERP - Sistema de gestão de produtos para Marketplace

- Objetivo: Sistema de gestão de produtos, clientes e vendas para Marketplace.

- Stack técnica: FastAPI + SQLAlchemy + Alembic + PostgreSQL.

## Módulos principais:

- Produtos

- Clientes

- Vendas

- Itens da venda
