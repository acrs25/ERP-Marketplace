# ERP-Marketplace
### ERP - Sistema de gestão para Marketplace

- Objetivo: Fornecer um sistema ERP voltado para a operação interna do Marketplace, com foco na gestão integrada de clientes, usuários e transações comerciais, garantindo organização, controle e eficiência nos processos da plataforma.

- Stack técnica: FastAPI + SQLAlchemy + Alembic + PostgreSQL.

## Módulos principais:

- Cliente

- Produto

- Transação

- Usuário

## Progresso atual
- Banco PostgreSQL configurado
- Alembic sincronizado
- Modelos criados e migrados
- Dados de teste inseridos e validados

## Próximos passos
- Integrar SQLAlchemy com FastAPI  
- Criar endpoints CRUD para cada módulo  
- Testar via Swagger UI  
- Implementar regras de negócio (comissão, estoque, relatórios)
